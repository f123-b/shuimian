# White-noise assets

These files are bundled locally so the Android app does not need an internet
connection while playing:

- `white-noise-cc0.mp3` — BigSoundBank sound 1037, “White Noise”, 5 minutes.
  Source: https://bigsoundbank.com/bruit-blanc-s1037.html
  License: CC0 / public-domain equivalent. Author: Joseph SARDIN.
- `white-noise-cc0.wav` — `noise.wav` from the Portland State Computers,
  Sound and Music sample repository.
  Source: https://github.com/pdx-cs-sound/wavs/blob/main/noise.wav
  License: CC0, as stated in the repository README. Author: Bart Massey.
